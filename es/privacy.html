No recopilamos ni recibimos tus datos.

TabParcel copia, guarda y abre los enlaces que eliges, en tu navegador. No envía tus enlaces al desarrollador ni a servidores de TabParcel.

Privacidad

Datos y almacenamiento

Las URL, los títulos, los textos pegados y los archivos se procesan localmente para las acciones que eliges. Permanecen en memoria durante el uso del popup. El proceso de apertura conserva temporalmente las URL solicitadas mientras termina la operación. No se envían al desarrollador ni se guardan en un historial propio.

Solo se conserva el idioma

chrome.storage.local guarda únicamente el idioma de la interfaz, detectado la primera vez o elegido después por ti. No usa sincronización. La primera vez se guarda el idioma detectado y después se respeta el que elijas. No guarda pestañas, filtros, selecciones ni textos. Desinstalar la extensión elimina esta preferencia.

Permisos

tabs permite leer títulos y URL cuando abres el popup, actualizas, copias o descargas. downloads inicia el TXT local. clipboardWrite copia lo que seleccionas; no se lee el portapapeles. storage conserva solo el idioma. No se piden permisos de sitios, historial, cookies ni acceso al contenido de las páginas. Incógnito requiere autorización manual en Chrome.

Archivos, portapapeles y páginas abiertas

El TXT y los enlaces copiados pueden contener direcciones privadas o parámetros sensibles. Quedan bajo tu control fuera de TabParcel; cerrar incógnito o desinstalar la extensión no los borra. Chrome mantiene sus registros habituales de descargas y navegación. Al abrir enlaces importados, el navegador contacta con los sitios y aplica sus cookies y su comportamiento normal.

Enlaces externos opcionales

No hay telemetría, analítica, cuentas ni servidores de TabParcel. Ko-fi se abre solo al pulsar Apoyar en Ko-fi. El creador y Más extensiones abren root-cr.com y root-cr.com/extensions tras un clic, sin referente. TabParcel no adjunta enlaces ni preferencias. Esos sitios aplican sus propias políticas; Ko-fi gestiona pagos y TabParcel no recibe sus resultados.

Uso limitado

El uso de la información recibida de las API de Chrome cumple la Política de Datos de Usuario de Chrome Web Store, incluidos los requisitos de Uso Limitado. Solo se usa para elegir, copiar, exportar e importar los enlaces solicitados. No se vende ni se usa para publicidad, perfiles o lectura humana por el desarrollador.

Este sitio y el soporte público

La documentación se aloja en GitHub Pages. Al visitarla, GitHub puede tratar datos técnicos de la solicitud, como la dirección IP, bajo su propia política. Este sitio no añade analítica, formularios ni cookies propias. Si abres una solicitud de soporte, GitHub procesa lo que decidas enviar y la solicitud es pública. No adjuntes listas privadas ni tokens.
