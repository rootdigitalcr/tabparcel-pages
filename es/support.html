No recopilamos ni recibimos tus datos.

TabParcel copia, guarda y abre los enlaces que eliges, en tu navegador. No envía tus enlaces al desarrollador ni a servidores de TabParcel.

SOPORTE

Ayuda cuando la necesitas.

Empieza por la guía y las soluciones a problemas frecuentes. Si el problema persiste, usa el registro público de soporte.

Comunica un problema

Incluye la versión de TabParcel, la de Chrome, el sistema operativo, los pasos y el resultado esperado. Usa URL de ejemplo y elimina información personal de las capturas.

Las solicitudes son públicas. No incluyas URL privadas o de incógnito, listas exportadas, contraseñas, tokens ni rutas personales. TabParcel no adjunta esos datos automáticamente.

Abrir una solicitud en GitHub ↗

GitHub trata solo lo que decidas enviar bajo su propia política. La guía puede leerse sin cuenta; publicar una solicitud puede requerir una cuenta de GitHub.
