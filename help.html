TabParcel copies, saves and opens the links you choose in your browser. It does not send your links to the developer or TabParcel servers.

DOCUMENTATION

From your tabs to a list.

Find only the links you need

Type a word in the Export search box to find it in tab titles or addresses. To pin a filter, type it and press Enter. It becomes a removable chip and leaves the box free for the next search.

Add more chips the same way. Remove one with × or use Clear all. Free text stays in the box. Chips use at most two rows and scroll if needed.

What is a domain?

It identifies the website in a URL. In https://www.youtube.com/watch?v=123, youtube.com identifies YouTube. The part after the slash identifies the page.

Type domain:youtube.com and press Enter. Use the full domain rather than just youtube. This also matches www.youtube.com and music.youtube.com, but excludes other websites that only mention YouTube.

Try these filters

domain:youtube.com
dominio:youtube.com
Only that website and its subdomains. You may also paste a complete URL after the prefix.
title:recipe
titulo:recipe
Titles containing “recipe”. The Spanish prefix título: also works.
url:pdf
Addresses containing “pdf”. This searches the address and does not check the file type.
-domain:youtube.com
The minus sign excludes a site. It also works with words and other filters.

Combine filters

Confirm domain:youtube.com with Enter, then domain:github.com. Tabs from either site appear. Add title:recipe to require that word in the title as well. All title, URL and exclusion conditions must match.

Commas are ordinary text. Use quotes for a complete phrase, for example title:"Hello, world". Without quotes, each word is searched separately.

The English and Spanish prefixes work regardless of the interface language. There is no filter for browsing mode; review the normal and incognito categories.

An empty or incomplete filter does not create a chip. If no results appear, remove a filter or correct it. To see everything, use Clear all and erase the free text too. Filters disappear when the popup closes.

Save only links from one website

  1. To start fresh, clear the filters and search text and uncheck any previous selection.
  2. Type domain:youtube.com and press Enter.
  3. Choose Select results. Only current matches are selected.
  4. Review the footer count and choose Copy links or Download list.

Category checkboxes act on the current search results too. Without a filter they select the entire category. You can select incognito tabs without displaying their links.

Searching preserves your selection

Changing a filter does not clear previously selected tabs. Category counters show current matches. The footer includes the whole selection, including hidden results. A warning indicates when selected links fall outside the filter. Those links are also copied or downloaded.

Show links (N) indicates how many incognito tabs match, without revealing their addresses.

Take your chosen pages with you

Copy link or Copy links sends the selected addresses to the clipboard, one per line. Download list creates a TXT file that TabParcel can import. Both actions preserve tab order and recheck the current tabs and incognito permission before including links.

The / shortcut focuses search when you are not editing another field. The refresh button reloads the tab list.

The TXT begins with # TabParcel v1, followed by one HTTP or HTTPS URL per line. It contains no titles or browsing-mode labels.

From a file or pasted text

In Import, choose a TXT created by TabParcel or select Paste text. Paste with Ctrl+V and choose Detect links or press Ctrl+Enter. You can also drag a TXT onto the import panel.

Review the list, select links and choose a normal or incognito window. No link is selected automatically. Pasted text removes duplicate URLs; files preserve duplicates and must begin with # TabParcel v1.

The limit is 500 links and 1 MiB per input. Opening more than 30 links asks for confirmation. Successfully opened links are unchecked; failed ones stay selected for retry.

Links are added to an existing window of the selected mode, preferring the window where you opened TabParcel. If none exists, a new window is created. Closing the popup while links are opening does not cancel the worker.

Choose what to reveal and include

Enable Allow in Incognito in TabParcel details. Use the incognito notice in the popup to open those details. You enable the permission yourself.

Incognito links start collapsed. Choose Show links to reveal them or Hide links to conceal them. They collapse again when you refresh, change sections or open another popup.

Only selected links are copied or downloaded. TabParcel does not store them. Closing incognito does not delete the clipboard or TXT. When imported, the destination is the mode you choose; the file itself does not record browsing mode.

Everything is processed in your browser

TabParcel processes links, pasted text and files on your device. Searches, selections and imported content disappear when the popup closes. Only your explicit interface-language preference is stored in your local Chrome profile. Your choice is remembered the next time you open TabParcel.

There are no accounts, analytics or servers. These help pages work offline. Ko-fi, the creator website and the extension catalog open only when clicked. Opening imported URLs contacts those websites normally.

Only HTTP and HTTPS links are supported. Internal Chrome pages and other special addresses cannot be exported.

Interface language

On first use, TabParcel checks Chrome’s interface language. If its identifier contains “es”, ignoring case, Spanish is used. All other cases use English.

Choose Español or English in the header to override it. Your choice is saved and shared by the popup and documentation, even if Chrome’s language changes. Tab content is not analyzed for language. Both languages’ filter prefixes keep working.

If something does not work

  • No tabs appear: refresh and clear filters. Only HTTP and HTTPS tabs in normal and authorized incognito windows are supported.
  • Incognito is missing: open TabParcel details at chrome://extensions, enable Allow in Incognito, and reopen the popup.
  • A file is rejected: use a UTF-8 TabParcel TXT, up to 1 MiB and 500 URLs. Use Paste text for a list without a header.
  • Opening failed: check the tabs already opened. Failed URLs remain selected; retry only those.
  • Copy fails: check the browser permission or use Download list.
  • You just updated: reload the extension at chrome://extensions and reopen the popup.
