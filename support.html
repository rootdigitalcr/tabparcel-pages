We don't collect or receive your data.

TabParcel copies, saves and opens the links you choose in your browser. It does not send your links to the developer or TabParcel servers.

SUPPORT

A hand when you need it.

Start with the guide and troubleshooting steps. If a problem remains, use the public support tracker.

Report a problem

Include the TabParcel version, Chrome version, operating system, steps and expected result. Use example URLs and remove personal information from screenshots.

Requests are public. Do not include private or incognito URLs, exported lists, passwords, access tokens or personal paths. TabParcel never attaches them automatically.

Open a request on GitHub ↗

GitHub handles only what you choose to submit under its own policy. No GitHub account is needed to read the guide; posting an issue may require one.
